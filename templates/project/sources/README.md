# sources/ — Raw Sources（不変層・このプロジェクト専用）

このプロジェクトの生データ（インタビュー録・デモ記録・アンケート結果・デスクリサーチのメモ等）を**人間が置く**ディレクトリ。

## ルール

- **AIは読むだけ。編集・削除しない。** 一次情報の置き場であり、後から書き換えると歴史性が壊れる。
- ファイル名は自由。取り込み（`/learning`）のときにAIがここを読み、事実／解釈を分離して**学びレコード**（`wiki/learnings/<PREFIX>-LEARN-NNN.md`）に新規作成で記録する（実験計画 `wiki/tests/<PREFIX>-TEST-NNN.md` のテストカードは検証後に書き換えない）。
- **架空/デモ・シミュレーションデータを置く場合は、ファイル冒頭に「架空・実証拠として扱わない」と明記する**（実データと誤認させない）。
